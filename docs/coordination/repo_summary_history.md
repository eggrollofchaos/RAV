It is not a verbatim changelog. The goal is to preserve useful historical
context without making the live summary unreadable.

## Maintenance Rule

When material is removed from `live_repo_summary.md`, preserve the substance
here in condensed form:

- enough detail to reconstruct the state transition
- enough detail to function as a lightweight audit trail
- not a verbatim copy of the removed live text

The live-summary window is configurable by repo cadence. Do not move material
here only because it is older than the configured window. Move it when it is no
longer useful in the live memo and enough newer active work has displaced it.
